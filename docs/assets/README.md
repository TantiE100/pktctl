# Brand assets

| File | Use |
|---|---|
| `logo-light.svg`, `logo-dark.svg` | Icon and wordmark for light and dark backgrounds; the top of the main README picks one with `prefers-color-scheme`. |
| `icon.svg` | The full icon, for 48 px and larger. |
| `icon-small.svg` | A simplified icon for 32 px and smaller: avatars, favicons and chat previews. |
| `social-preview.png` | 1280 x 640 image for link previews. GitHub does not read it from the repository; upload it in **Settings → General → Social preview**. |
| `example-two-sites.png` | Screenshot of the two-site OSPF example built with pktctl, shown in the main README. |

The icon shows a packet envelope, as Packet Tracer draws PDUs in simulation
mode, inside a ring of network nodes. The palette is graphite (`#2A2F37` to
`#15181D`) with a single amber accent (`#F2A33A`; `#C4780F` for text on light
backgrounds).

The wordmark is set in JetBrains Mono ExtraBold, licensed under the SIL Open
Font License 1.1, and converted to outlines so it renders the same everywhere.
